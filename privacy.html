Zero Notes

Privacy policy

Zero Notes saves your highlights and comments on your device. It has no account, cloud sync, analytics, or advertising. The extension does not send your notes or browsing activity to the developer or to third parties.

Website access and local storage

The extension reads the current tab’s URL when you open its popup. When you enable Zero Notes on a site, it requests access to that site so it can place annotations on the page. Annotating local HTML files also requires allowing file access in your browser.

The extension stores enabled sites, page URLs, highlighted text and nearby text used to locate it, comments, and display preferences in your browser profile. The demo and embedded script use the website’s local browser storage.

Exports and the optional CLI

You can download a site’s notes as a JSON file or copy a page’s notes to the clipboard as Markdown. If you install the Chrome command line helper and choose Connect CLI, the extension shares saved notes with that helper on your device. Programs running as your OS user can request notes for any site while the helper is connected. Choose Disconnect CLI to end that access.

Deleting notes

Delete individual notes or comments in the notes interface. Disabling a site stops annotation on that site and keeps its saved notes. Removing the extension clears its browser storage. For the demo or embedded script, clear the site’s browser data to remove its saved notes. Downloaded files are separate copies.

Chrome Web Store Limited Use

Zero Notes uses data obtained through Chrome APIs only to provide its annotation and export features, in accordance with the Chrome Web Store User Data Policy, including its Limited Use requirements.

Contact

For questions about this policy, use the project’s GitHub issue tracker. Issues are public, so leave out personal information and note contents.
